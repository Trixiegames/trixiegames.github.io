# Politický přehled — publikovaná aplikace

Zdrojový kód a vývoj: https://github.com/davhab-dev/Politicky-prehled

Veřejný web: https://davhab.com/politicky-prehled/

Tato složka obsahuje publikovaný výstup, aktuální zprávy a živý archiv. Hodinový workflow načítá zdrojový kód ze samostatného repozitáře, zachovává archiv a publikuje nové vydání. Úpravy vzhledu a logiky provádějte ve zdrojovém repozitáři.
